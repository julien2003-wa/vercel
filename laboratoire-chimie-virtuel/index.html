📖 Nomenclature organique

Fiche de référence + quiz d'entraînement

Alcanes — CₙH₂ₙ₊₂

  • Suffixe -ane
  • Chaîne saturée
  • Ex : CH₄ méthane, C₄H₁₀ butane

Alcènes — CₙH₂ₙ

  • Suffixe -ène
  • Une liaison double C=C
  • Indice de position si besoin

Alcynes — CₙH₂ₙ₋₂

  • Suffixe -yne
  • Une liaison triple C≡C

Alcools — R-OH

  • Suffixe -ol
  • Classes I, II, III selon le carbone fonctionnel

Dérivés halogénés — R-X

  • Préfixe halogéno-
  • X = F, Cl, Br, I

Acides carboxyliques — R-COOH

  • Suffixe -oïque
  • Ex : acide éthanoïque

Esters — R-COO-R'

  • -oate de ...-yle
  • Ex : éthanoate d'éthyle
